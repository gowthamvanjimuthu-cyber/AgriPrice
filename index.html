About AgriPrice

A Simple Digital Platform for Agricultural Information

AgriPrice is designed as a farmer-focused crop price comparison Android application. The project combines modern Android development with Firebase cloud services.

  • Kotlin-based Android application
  • Jetpack Compose user interface
  • Material 3 design system
  • Firebase Authentication
  • Cloud Firestore database
  • Repository-based architecture
  • Crop price comparison and market exploration
  • Farmer-focused utilities

The full project is designed as an Android application with Firebase Authentication and Cloud Firestore integration. Live agricultural market API integration is planned as future work.
